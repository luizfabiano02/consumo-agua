💧 Classificação do Consumo de Água

Este projeto apresenta um programa simples desenvolvido em Python para classificar o consumo mensal de água de diferentes tipos de imóveis.

O usuário informa o tipo de imóvel e o consumo em m³. A partir dessas informações, o programa utiliza estruturas de decisão para apresentar uma mensagem de orientação sobre o consumo.

🐍 Conceitos praticados
if, elif e else
Operadores and, or e not
Operadores de comparação
Entrada de dados com input()
Conversão de valores com float()
▶️ Como utilizar
Execute o arquivo Python.
Informe o tipo de imóvel: casa, apartamento ou comercial.
Informe o consumo mensal de água em m³.
O programa analisará os dados e exibirá a classificação correspondente.
🎯 Objetivo

Projeto desenvolvido para praticar lógica de programação e tomada de decisão em Python, utilizando uma situação do cotidiano como exemplo. Texto refinado por IA.
